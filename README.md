# KDK Interests

Holding company site for **KDK Interests LLC** — the parent company and front door for the companies it holds.

```
KDK Interests LLC   (this site)
  → KDK TX         homes  → https://kdktx.com
  → KDK Media      stories
```

## Pages

- `/` — The house
- `/tx` — KDK TX (property)
- `/media` — KDK Media (studio)
- `/about` — How the house is built
- `/contact` — Write to a room

## Local

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```

## Notes

- Rental applications and the previous static KDK TX site live in `legacy-kdktx/` (Palmer photos, lease, application form). Nothing from that site was deleted.
- Live rentals remain at [kdktx.com](https://kdktx.com).
